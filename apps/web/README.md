# IT Repair System - Admin Frontend

ระบบแจงซอมอปกรณ IT ผาน LINE Official Account - Admin Dashboard

##  Overview

แอปพลเคชน Next.js 14 (App Router) ทใชสำหรบจดการแจงซอมอปกรณ IT ในองคกร

##  Tech Stack

- **Framework**: Next.js 14+ (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **UI Components**: shadcn/ui
- **HTTP Client**: Axios
- **State Management**: TanStack React Query (v5)
- **Real-time**: Socket.IO Client
- **Forms**: React Hook Form + Zod
- **Date**: date-fns
- **Icons**: Lucide React
- **Notifications**: Sonner
